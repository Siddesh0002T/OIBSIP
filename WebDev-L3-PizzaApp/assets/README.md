# 📁 Assets Directory

This folder is designated for storing all visual assets, demo evidence, and official verification records for the **Pizza Delivery Full-Stack Application** project.

## 🗂️ Folder Structure

- **`/screenshots`**: Place your application UI screenshots here (e.g., `dashboard.png`, `pizza-builder.png`, `checkout.png`, `admin-inventory.png`, `live-tracking.png`).
- **`/certificates`**: Place your official Oasis Infobyte completion certificates and letters of recommendation here (e.g., `oibsip-completion-certificate.png`, `recommendation-letter.png`).

Once you place your images in these folders, the links in the main `README.md` will automatically render them!
